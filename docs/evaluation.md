# 系统评估方案

## 1. 数据外传行为判定准确率

评估系统能否正确识别外部传输行为。

可使用人工标注的日志样本作为基准，统计：

- 真正例：实际为外部传输，系统也判定为外部传输；
- 假正例：实际不是外部传输，系统误判为外部传输；
- 假负例：实际是外部传输，系统未识别；
- 真负例：实际不是外部传输，系统也未识别为外部传输。

可计算 precision、recall 和 F1-score。

## 2. 非计划外传事件识别准确率

非计划外传事件指实际数据流未在声明规则中允许，且目标为外部系统或未知系统。

评估方法：

- 构造包含正常外传和异常外传的日志集合；
- 使用人工标注或规则标注确定真实标签；
- 对比系统输出的 `external_unapproved` 结果；
- 统计识别准确率、召回率和误报率。

## 3. 风险评分合理性

风险评分应能体现字段敏感性、外部传输和声明违规的综合影响。

评估方法：

- 检查高敏感字段外传是否获得更高风险分；
- 检查合规内部低敏感字段是否保持低风险；
- 检查用途不一致事件是否高于普通合规事件；
- 邀请安全治理人员对风险排序进行人工评审。

可使用 Spearman 相关系数评估系统风险排序与人工排序的一致性。

## 4. 响应时间

响应时间评估包括：

- 策略文件加载时间；
- 日志文件解析时间；
- 合规检测时间；
- 风险评分时间；
- 图构建和 HTML 生成时间；
- Streamlit 页面交互响应时间。

在模拟数据中可记录端到端检测耗时。接入真实日志后，应按日志规模分层评估，例如 1 万、10 万、100 万条事件。

## 5. 图谱可视化效果

图谱可视化可以从以下角度评估：

- 节点和边是否易于区分；
- 高风险路径是否醒目；
- tooltip 是否能提供足够解释信息；
- 风险边标签是否清晰；
- 图谱在常见屏幕尺寸下是否适合展示；
- Streamlit 页面中是否避免过度嵌套滚动。

可以通过用户访谈或任务完成时间评估可用性。

## 6. 模拟数据集构造方式

模拟数据集应覆盖以下类型：

- 完全符合声明规则的正常数据流；
- 未声明字段传输；
- 未声明外部目标传输；
- 高敏感字段外传；
- 未知外部系统接收；
- 用途不一致；
- 高频传输；
- 不同敏感等级字段混合传输。

当前 `examples/actual_flow_logs.csv` 包含 35 条模拟日志，覆盖正常行为和多类异常行为。

## 7. 接入真实企业数据流日志时的评估方案

接入真实企业数据流日志时，建议按以下步骤评估：

1. 与数据治理团队确认声明数据流规则格式；
2. 将真实日志映射为 `FlowEvent` 所需字段；
3. 对部分样本进行人工标注；
4. 用人工标注结果评估合规检测准确率；
5. 与现有审计告警系统对比召回和误报；
6. 评估不同日志规模下的处理时间；
7. 与安全运营人员共同校准风险评分权重；
8. 将高风险事件输出为审计报告或告警工单。

真实环境中还需要考虑脱敏、访问控制、日志最小化和审计留痕，避免检测系统本身引入新的数据安全风险。
